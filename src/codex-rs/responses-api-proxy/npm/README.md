# tokencode-responses-api-proxy

<p align="center"><code>npm i -g tokencode-responses-api-proxy</code> to install <code>codex-responses-api-proxy</code></p>

This package distributes the prebuilt [Responses API proxy binary](https://github.com/miuiadmin/tokencode/tree/main/src/codex-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/codex-responses-api-proxy.js --help
```

Refer to [`src/codex-rs/responses-api-proxy/README.md`](https://github.com/miuiadmin/tokencode/blob/main/src/codex-rs/responses-api-proxy/README.md) for detailed documentation.
