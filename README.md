# TokenCode

**An open-source super coding agent.**

A powerful, open-source AI coding agent that helps you build software faster — right in your terminal.

[English](./README.md) · [简体中文](./README.zh-CN.md)

</div>

---

## ✨ Features

- 🤖 **Super Coding Agent** — autonomous, multi-step task execution
- 🔌 **Multi-Model** — bring your own models and providers
- 🛠️ **Tool Use** — file editing, shell, search, and more
- 🧠 **Context-Aware** — understands your whole codebase
- 💻 **Runs in Your Terminal** — fast, native Rust core
