# TokenCode

**一个开源的超级代码智能体。**

强大的开源 AI 代码智能体，在你的终端里帮你更快地写代码。

[English](./README.md) · [简体中文](./README.zh-CN.md)

## ✨ 特性

- 🤖 **超级代码智能体** — 自主、多步骤的任务执行
- 🔌 **多模型支持** — 接入你自己的模型与服务商
- 🛠️ **工具调用** — 文件编辑、终端、搜索等
- 🧠 **上下文感知** — 理解你的整个代码库
- 💻 **终端运行** — 原生 Rust 核心，快速高效
